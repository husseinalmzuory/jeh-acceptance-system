# منظومة قبولات النشر — JEH

منظومة داخلية لإصدار وأرشفة والتحقق من كتب قبول النشر في مجلة التربية للعلوم الإنسانية، جامعة الموصل.

## النطاق

- حساب دخول واحد للمجلة.
- إصدار وحفظ قبولات النشر فقط.
- لا تستبدل المنظومة منصة OJS ولا تتابع مراحل البحث.
- قاعدة البيانات والمصادقة عبر Supabase.
- تخزين المرفقات الداخلية فقط في Supabase Storage.
- **ملفات PDF لا تُخزن في Supabase**؛ تُنشأ من البيانات المحفوظة عند الإصدار أو عند طلب التنزيل من الأرشيف.
- الواجهة مبنية باستخدام React وVite وتنشر عبر GitHub Pages.

## الوظائف الحالية

- إنشاء قبول لباحث واحد وحتى ستة باحثين مع مكان عمل مستقل لكل باحث.
- معاينة كتاب القبول قبل الحفظ.
- إنشاء وتنزيل PDF وطباعته.
- أرشيف القبولات والبحث.
- تعديل القبول مع سبب إلزامي للتعديل وسجل إصدارات محفوظ.
- فتح النسخ السابقة للقبول.
- إلغاء القبول دون حذفه وحفظ سبب وتاريخ الإلغاء.
- حذف نهائي مؤكد للقبول ونسخه ومرفقاته عند الحاجة الإدارية.
- رابط تحقق عام فريد لكل قبول.
- بوابة تحقق عامة برقم القبول.
- QR تلقائي داخل كتاب القبول لفتح التحقق مباشرة.
- أرشيف متقدم مع البحث والفلاتر الزمنية والحالة والترتيب وتقسيم النتائج إلى صفحات.
- مرفقات داخلية خاصة بالموظف، مع روابط تنزيل مؤقتة وآمنة.
- صفحة إدارة لبيانات المجلة الثابتة.
- إحصاءات دقيقة للسنة والشهر والحالات.
- تصدير CSV ونسخة احتياطية JSON.
- تغيير كلمة مرور حساب المجلة وتسجيل خروج شامل.

## إعداد البيئة

انسخ `.env.example` إلى `.env.local` وأضف عنوان مشروع Supabase والمفتاح القابل للنشر. لا تضع أي مفتاح سري أو `service_role` في الواجهة أو المستودع.

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

## قاعدة البيانات

ملفات SQL مرتبة داخل `supabase/migrations`. يجب تنفيذها بالتسلسل في SQL Editor داخل Supabase.

الكتابة على السجلات الأساسية تتم عبر وظائف RPC المخصصة، وليس عبر تعديل الجداول مباشرة من الواجهة. صفحة التحقق العامة لا تحصل على الملاحظات الداخلية أو بيانات الإدارة.

## PDF والتخزين

البيانات هي المصدر الرسمي للقبول. عند الحاجة إلى PDF، تعيد المنظومة إنشاءه من السجل الحالي أو من الإصدار التاريخي المختار. هذا يمنع تكرار تخزين ملفات PDF ويضمن إمكانية إعادة التنزيل لاحقًا.

المرفقات الداخلية تختلف عن PDF: يتم رفعها إلى bucket خاص باسم `acceptance-attachments` وتظل غير عامة.
