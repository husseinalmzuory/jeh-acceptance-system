# قائمة الاختبار النهائي — منظومة قبولات النشر JEH

تُنفذ هذه القائمة قبل اعتماد الإصدار 1.0 وتسليم المنظومة للموظف.

## A. تسجيل الدخول والأمان

- [ ] تسجيل الدخول بالحساب الصحيح ينجح.
- [ ] فتح رابط الإدارة بدون جلسة يعيد المستخدم إلى تسجيل الدخول.
- [ ] فتح الأرشيف المتقدم بدون جلسة لا يكشف السجلات.
- [ ] تغيير كلمة المرور من صفحة الإدارة يعمل.
- [ ] تسجيل الخروج العادي يعمل.
- [ ] اختبار التسجيل الشامل بعد حفظ بيانات الدخول الجديدة في مكان آمن.

## B. إصدار قبول جديد

### باحث واحد

- [ ] الاستمارة الجديدة تبدأ فارغة من البيانات التجريبية.
- [ ] تاريخ الكتاب وتاريخ القبول يبدآن بتاريخ اليوم المحلي.
- [ ] إدخال رقم قبول جديد يعمل.
- [ ] إدخال الباحث ومكان العمل يعمل.
- [ ] العنوان العربي والإنجليزي يظهران في المعاينة.
- [ ] ترتيب تواريخ الاستلام ثم المراجعة ثم القبول يُقبل.
- [ ] ترتيب تواريخ خاطئ يُرفض.
- [ ] الملاحظة الداخلية لا تظهر في كتاب القبول.

### عدة باحثين

- [ ] إضافة باحث ثانٍ تعمل.
- [ ] إضافة حتى ستة باحثين تعمل.
- [ ] مكان عمل مستقل لكل باحث يظهر بصورة صحيحة.
- [ ] حذف باحث قبل الإصدار يعمل.

## C. PDF والطباعة

- [ ] تنزيل PDF بعد إصدار قبول جديد يعمل.
- [ ] اسم الملف يتضمن رقم القبول.
- [ ] الملف صفحة A4 واحدة.
- [ ] بيانات الاتصال ظاهرة.
- [ ] اسم رئيس التحرير وصفته ظاهران.
- [ ] QR ظاهر وقابل للمسح.
- [ ] QR يفتح صفحة التحقق الصحيحة.
- [ ] الطباعة من المتصفح تحافظ على التصميم.
- [ ] اختبار عنوان عربي طويل.
- [ ] اختبار عنوان إنجليزي طويل.
- [ ] اختبار ستة باحثين والتأكد من بقاء الكتاب مقروءًا في صفحة واحدة.

## D. التحقق العام

- [ ] رابط التحقق الفريد يفتح بدون تسجيل دخول.
- [ ] التحقق برقم القبول يعمل.
- [ ] يظهر رقم الكتاب والعنوان والباحثون والتواريخ.
- [ ] الملاحظات الداخلية لا تظهر.
- [ ] إدخال رقم غير موجود يعطي رسالة مناسبة.

## E. الأرشيف العادي

- [ ] البحث برقم القبول يعمل.
- [ ] البحث باسم الباحث يعمل.
- [ ] البحث بعنوان البحث يعمل.
- [ ] فتح تفاصيل القبول يعمل.
- [ ] إعادة تنزيل PDF تعمل.
- [ ] الطباعة تعمل.
- [ ] نسخ رابط التحقق يعمل.

## F. الأرشيف المتقدم

- [ ] البحث برقم القبول يعمل.
- [ ] البحث باسم أي باحث مشارك يعمل.
- [ ] البحث بمكان عمل الباحث يعمل.
- [ ] البحث بالعنوان العربي والإنجليزي يعمل.
- [ ] التصفية حسب السنة تعمل.
- [ ] التصفية حسب الحالة تعمل.
- [ ] التصفية من تاريخ/إلى تاريخ تعمل.
- [ ] الترتيب الأحدث/الأقدم يعمل.
- [ ] عدد النتائج صحيح.
- [ ] تقسيم الصفحات يظهر عند وجود أكثر من 20 نتيجة.
- [ ] نافذة التفاصيل تعرض البيانات الصحيحة.

## G. التعديل والإصدارات

- [ ] تعديل قبول محفوظ يعمل.
- [ ] سبب التعديل إلزامي.
- [ ] الإصدار الجديد يصبح النسخة الحالية.
- [ ] النسخة القديمة تبقى في سجل الإصدارات.
- [ ] فتح النسخة السابقة يعمل.
- [ ] إعادة إنشاء PDF بعد التعديل تعمل.

## H. الإلغاء

- [ ] إلغاء قبول ساري يتطلب سببًا.
- [ ] حالة السجل تصبح ملغى.
- [ ] سبب وتاريخ الإلغاء يظهران في الأرشيف.
- [ ] زر التعديل لا يعود متاحًا للقبول الملغى.
- [ ] صفحة التحقق تعرض «كتاب القبول ملغى».
- [ ] PDF المعاد تنزيله للقبول الملغى يحمل علامة مائية «ملغى».
- [ ] محاولة تعديل سجل ملغى من المسار الرسمي تفشل.

## I. المرفقات

- [ ] رفع PDF أو مستند صغير يعمل.
- [ ] يظهر اسم الملف والحجم وتاريخ الرفع.
- [ ] فتح المرفق يولد رابطًا مؤقتًا ويعمل.
- [ ] المرفق لا يظهر في صفحة التحقق العامة.
- [ ] حذف المرفق يعمل.
- [ ] ملف أكبر من 25 MB يُرفض من الواجهة.

## J. إعدادات المجلة

- [ ] صفحة الإدارة تعرض بيانات المجلة.
- [ ] تعديل البريد وحفظه يعمل.
- [ ] يظهر البريد الجديد في معاينة كتاب القبول.
- [ ] تعديل الهاتف يعمل.
- [ ] تعديل اسم رئيس التحرير وصفته يعمل.
- [ ] تعديل ISSN ورقم الإيداع يعمل.
- [ ] تعديل النص الرسمي ينعكس في الكتاب.
- [ ] إعادة القيم الرسمية المطلوبة بعد الاختبار.

## K. الإحصاءات والتصدير

- [ ] إجمالي القبولات صحيح.
- [ ] عدد قبولات السنة الحالية صحيح.
- [ ] عدد قبولات الشهر الحالي صحيح.
- [ ] عدد السارية والملغاة صحيح.
- [ ] أحدث رقم قبول صحيح.
- [ ] تصدير CSV يعمل ويفتح بالعربية بصورة سليمة.
- [ ] تنزيل نسخة JSON الاحتياطية يعمل.

## L. حالات الخطأ

- [ ] محاولة إصدار رقم قبول مكرر تعطي رسالة واضحة.
- [ ] قطع الإنترنت قبل الحفظ لا ينشئ سجلًا ناقصًا.
- [ ] إذا حُفظ السجل وفشل PDF يمكن إعادة تنزيله من الأرشيف.
- [ ] فشل تحميل QR لا يمنع حفظ القبول أو الوصول إلى بوابة التحقق النصية.

## M. الأجهزة

- [ ] واجهة الحاسوب تعمل.
- [ ] بوابة التحقق تعمل على الهاتف.
- [ ] QR يُقرأ بكاميرا هاتف حقيقية.
- [ ] الأرشيف المتقدم قابل للاستخدام على شاشة صغيرة.

## شرط اعتماد الإصدار 1.0

لا يُعتمد الإصدار النهائي إلا بعد نجاح الأقسام الأساسية: A وB وC وD وG وH، وعدم وجود خطأ يؤدي إلى فقدان سجل قبول محفوظ.
