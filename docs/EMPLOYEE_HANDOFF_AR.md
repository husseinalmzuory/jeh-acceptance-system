# دليل تسليم منظومة قبولات النشر للموظف

الإصدار: **1.0.0**  
الجهة: مجلة التربية للعلوم الإنسانية - جامعة الموصل

## 1. قبل التسليم

- تأكد من صحة اسم المجلة والبريد والهاتف واسم رئيس هيئة التحرير.
- تأكد من ظهور الشعار والتوقيع والختم في المعاينة وPDF.
- احذف السجلات والمرفقات التجريبية غير المطلوبة.
- نزّل نسخة احتياطية JSON واحفظها في مكان آمن تابع للمجلة.
- سلّم بريد حساب المجلة وكلمة المرور بطريقة خاصة، ولا ترسلهما في مجموعة عامة.

## 2. تدريب الموظف

ينفذ الموظف أمام المسؤول العمليات الآتية:

1. تسجيل الدخول.
2. إصدار قبول لباحث واحد.
3. إضافة باحثين مع مكان عمل مستقل لكل باحث.
4. مراجعة المعاينة وتنزيل PDF.
5. البحث عن القبول في الأرشيف.
6. تعديل القبول وكتابة سبب التعديل.
7. فتح إصدار سابق.
8. رفع مرفق داخلي وتنزيله وحذفه.
9. نسخ رابط التحقق وتجربة QR.
10. إلغاء قبول تجريبي.
11. حذف قبول تجريبي بعد قراءة التحذير.
12. تصدير CSV وتنزيل نسخة JSON.

## 3. قواعد التشغيل اليومية

- راجع الرقم والأسماء وأماكن العمل والعنوان والتواريخ قبل الإصدار.
- استخدم **إلغاء القبول** إذا كان يجب الاحتفاظ بالسجل الإداري.
- استخدم **حذف القبول** للسجلات التجريبية أو عند وجود قرار صريح بالمحو النهائي فقط.
- لا تُخزن ملفات PDF في Supabase؛ أعد تنزيلها من الأرشيف عند الحاجة.
- لا تعدّل جداول Supabase أو ملفات GitHub يدويًا أثناء الاستخدام اليومي.
- لا تشارك كلمة المرور مع أشخاص غير مخولين.

## 4. النسخ الاحتياطي

- نزّل نسخة JSON بعد أي دفعة مهمة من القبولات، وبحد أدنى مرة أسبوعيًا.
- احفظ نسختين في موقعين مختلفين تابعين للمجلة.
- استخدم اسمًا يتضمن التاريخ، مثل:
  `jeh-acceptances-backup-2026-09-04.json`
- لا تعتبر ملفات PDF بديلًا عن نسخة البيانات الاحتياطية.

## 5. عند حدوث مشكلة

1. لا تكرر الضغط على زر الإصدار.
2. تحقق من اتصال الإنترنت.
3. حدّث الصفحة مرة واحدة.
4. ابحث عن رقم القبول في الأرشيف قبل محاولة إصداره مجددًا.
5. استخدم دليل `RECOVERY_GUIDE_AR.md`.
6. لا تحذف بيانات أو تنفذ SQL دون إشراف تقني.

## 6. اختبار الاستلام

يُعد التسليم مكتملًا عندما يستطيع الموظف دون مساعدة:

- إصدار قبول وتنزيله.
- العثور عليه في الأرشيف.
- تعديله وفتح نسخته السابقة.
- معرفة الفرق بين الإلغاء والحذف النهائي.
- إنشاء نسخة احتياطية.
- تسجيل الخروج والدخول مجددًا.

## 7. معلومات النسخة

- الإصدار المعتمد: `v1.0.0`
- الاستضافة: GitHub Pages
- قاعدة البيانات والمصادقة والتخزين الخاص: Supabase
- ملفات PDF: تُنشأ داخل المتصفح عند الطلب ولا تُخزن في قاعدة البيانات
